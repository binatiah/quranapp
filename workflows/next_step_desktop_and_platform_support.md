# خطة العمل: دعم منصات التشغيل وتهيئة SQLite FFI وقاعدة البيانات (Desktop & Cross-Platform Support)

## اسم التدفق

`next_step_desktop_and_platform_support`

## الأهداف المنجزة

1. **تهيئة SQLite عبر FFI لسطح المكتب**:
   - تفعيل `sqfliteFfiInit()` و `databaseFactory = databaseFactoryFfi` عند الإقلاع على منصات Windows و Linux و macOS داخل `lib/main.dart`.
2. **المسار التخزيني الدائم المخصص**:
   - استخدام `getApplicationSupportDirectory()` عبر `path_provider` لضمان كتابة ونسخ قاعدة البيانات في مسار AppData المناسب لكل مستخدم دون مشاكل أذونات.
3. **حماية التوافق ومعالجة رسائل بيئة المتصفح**:
   - إضافة تحقق واضح عبر `kIsWeb` لمنع الانهيارات الصامتة وعرض رسالة إرشادية واضحة للمستخدم.
4. **تحديث وتصحيح الاختبارات الشاملة**:
   - تدقيق عتبة جذور القرآن (1968 جذراً معتمداً) ونجاح جميع الاختبارات الـ 78 بنسبة 100%.

## الخطوات القادمة للمتابعة

1. **التشغيل التجريبي المباشر على Windows Desktop**:
   - تنفيذ `flutter run -d windows` والتحقق من سلاسة التنقل وعرض السور بالرسم العثماني.
2. **التحقق من حزمة الإنتاج وتجهيز بناء التطبيق لسطح المكتب والأندرويد**:
   - فحص استهلاك الذاكرة وسرعة استجابة الاستعلامات عند أول تشغيل أثناء نسخ قاعدة البيانات (quran.db).
3. **دراسة دعم الويب مستقبلاً عند الطلب (WebAssembly Integration)**:
   - في حال الرغبة بدعم الويب، إعداد `sqflite_common_ffi_web` مع `sqlite3.wasm` في `web/`.
